# Update Server Setup & Configuration

This document explains how to set up the update distribution server for W3Ai Browser.

## Server Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                   W3Ai Update Server                         │
│              updates.w3ai.dev (your domain)                  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                    DNS Provider                              │
│              (CloudFlare, Route53, etc.)                     │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                 CDN (optional)                               │
│              (CloudFlare, CloudFront, etc.)                  │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│              Nginx Web Server                                │
│         (SSL/TLS, compression, caching)                      │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│            Update Manifest Files                             │
│                 (update.xml)                                 │
│              Release DMG Files                               │
│              Checksums & Metadata                            │
└─────────────────────────────────────────────────────────────┘
```

## Server Directory Structure

```
/srv/w3ai-updates/
│
├── dev/                           # Development channel
│   └── macos/
│       └── update.xml             (Firefox checks here)
│
├── rc/                            # Release candidate channel
│   └── macos/
│       └── update.xml
│
├── prod/                          # Production channel
│   └── macos/
│       └── update.xml             ← Users download from here
│
└── v151.0.0/                      # Release artifacts
    ├── W3AiBrowser-v151.0.0.dmg   (207 MB, signed/notarized)
    ├── checksums.txt              (SHA512 hashes)
    ├── manifest.json              (metadata)
    └── metadata/
        ├── release-notes.md
        └── build-info.json

# Later releases:
v151.0.1/, v152.0.0/, v153.0.0/, etc.
```

## Prerequisites

- Linux server (Ubuntu 20.04+ recommended)
- 500GB+ storage for future releases
- Static IP address
- Domain name (updates.w3ai.dev)
- SSL/TLS certificate (auto-generated by Certbot)
- Nginx web server
- SSH access

## Step 1: Server Installation (One-time Setup)

### 1.1 Create Deploy User

```bash
# SSH to your server as root
ssh root@your-server-ip

# Create dedicated deploy user
useradd -m -s /bin/bash deploy
usermod -aG www-data deploy

# Set up SSH keys for deploy user
sudo -u deploy mkdir -p /home/deploy/.ssh
# Copy your public key to /home/deploy/.ssh/authorized_keys
# chmod 700 /home/deploy/.ssh
# chmod 600 /home/deploy/.ssh/authorized_keys
```

### 1.2 Create Updates Directory

```bash
# As root
mkdir -p /srv/w3ai-updates/{dev,rc,prod}/macos
mkdir -p /srv/w3ai-updates/v151.0.0/metadata

# Set permissions
chown -R deploy:www-data /srv/w3ai-updates
chmod -R 755 /srv/w3ai-updates
```

### 1.3 Install Nginx

```bash
# Update system
apt-get update && apt-get upgrade -y

# Install Nginx
apt-get install -y nginx

# Install certbot for SSL
apt-get install -y certbot python3-certbot-nginx

# Enable nginx
systemctl enable nginx
systemctl start nginx
```

### 1.4 Configure Nginx

Create `/etc/nginx/sites-available/updates.w3ai.dev`:

```nginx
# HTTP redirect to HTTPS
server {
    listen 80;
    server_name updates.w3ai.dev;
    
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }
    
    location / {
        return 301 https://$server_name$request_uri;
    }
}

# HTTPS main server
server {
    listen 443 ssl http2;
    server_name updates.w3ai.dev;
    
    # SSL certificates (generated by Certbot)
    ssl_certificate /etc/letsencrypt/live/updates.w3ai.dev/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/updates.w3ai.dev/privkey.pem;
    
    # SSL configuration
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    
    # Logging
    access_log /var/log/nginx/updates.w3ai.dev.access.log;
    error_log /var/log/nginx/updates.w3ai.dev.error.log;
    
    # Security headers
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "no-referrer-when-downgrade" always;
    add_header Content-Security-Policy "default-src 'self'" always;
    
    # Compression
    gzip on;
    gzip_types text/xml application/xml application/xml+rss text/plain;
    gzip_disable "msie6";
    
    # Root directory for updates
    root /srv/w3ai-updates;
    
    # Update manifests (don't cache)
    location ~ /(dev|rc|prod)/macos/update\.xml$ {
        add_header Content-Type "application/xml; charset=utf-8";
        add_header Cache-Control "no-cache, no-store, must-revalidate";
        add_header Pragma "no-cache";
        add_header Expires "0";
        expires -1;
    }
    
    # Release files (cache long-term)
    location ~ /v[0-9]+\.[0-9]+\.[0-9]+/ {
        add_header Cache-Control "public, max-age=31536000, immutable";
        expires 365d;
    }
    
    # Checksums file
    location ~ checksums\.txt$ {
        add_header Content-Type "text/plain";
        add_header Cache-Control "max-age=3600";
        expires 1h;
    }
    
    # Metadata
    location ~ /metadata/ {
        add_header Content-Type "application/json";
        add_header Cache-Control "max-age=3600";
        expires 1h;
    }
    
    # Default: serve files
    location / {
        try_files $uri =404;
    }
    
    # Deny hidden files
    location ~ /\. {
        deny all;
    }
}
```

Enable the site:

```bash
ln -s /etc/nginx/sites-available/updates.w3ai.dev \
      /etc/nginx/sites-enabled/updates.w3ai.dev

# Test nginx config
nginx -t

# Restart nginx
systemctl restart nginx
```

### 1.5 Get SSL Certificate

```bash
# Run certbot
certbot certonly --webroot \
  -w /var/www/certbot \
  -d updates.w3ai.dev

# Set up auto-renewal
systemctl enable certbot.timer
systemctl start certbot.timer
```

### 1.6 Configure DNS

In your DNS provider (CloudFlare, Route53, etc.):

```
Type:   A
Host:   updates
Domain: w3ai.dev
Value:  [your-server-ip]

Or CNAME if using CDN:
Type:   CNAME
Host:   updates
Domain: w3ai.dev
Value:  [your-cdn-domain]
```

Test DNS resolution:

```bash
# From your local machine
nslookup updates.w3ai.dev
# Should return your server IP
```

## Step 2: Initial Content Upload

### 2.1 Upload Update Manifests

```bash
# Create development manifest
cat > /tmp/dev-update.xml << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<updates>
  <update 
    type="minor" 
    version="151.0.0-dev" 
    extensionVersion="151.0.0" 
    buildID="20240406000000"
  >
    <patch 
      type="complete" 
      URL="https://updates.w3ai.dev/v151.0.0/W3AiBrowser-v151.0.0-dev.dmg" 
      hashFunction="sha512" 
      hashValue="[hash]" 
      size="207000000"
    />
  </update>
</updates>
EOF

# Upload to server
ssh deploy@updates.w3ai.dev << 'SSH'
cat > /srv/w3ai-updates/dev/macos/update.xml << 'EOF'
[contents of /tmp/dev-update.xml]
EOF
chmod 644 /srv/w3ai-updates/dev/macos/update.xml
SSH

# Repeat for rc/ and prod/ channels
```

### 2.2 Upload Release Files

```bash
# Upload DMG file (large, may take time)
scp -p obj-x86_64-apple-darwin25.3.0/dist/W3AiBrowser-v151.0.0.dmg \
    deploy@updates.w3ai.dev:/srv/w3ai-updates/v151.0.0/

# Upload checksums
echo "$(shasum -a 512 W3AiBrowser-v151.0.0.dmg)" | \
ssh deploy@updates.w3ai.dev 'cat > /srv/w3ai-updates/v151.0.0/checksums.txt'

# Verify upload
ssh deploy@updates.w3ai.dev 'ls -lh /srv/w3ai-updates/v151.0.0/'
```

## Step 3: Monitoring & Maintenance

### 3.1 Monitor Server Health

```bash
# Create health check script
cat > /home/deploy/check-updates.sh << 'BASH'
#!/bin/bash
echo "=== W3Ai Updates Server Health Check ==="
echo

echo "1. Disk usage:"
df -h /srv/w3ai-updates

echo -e "\n2. Manifest files:"
ls -lh /srv/w3ai-updates/{dev,rc,prod}/macos/update.xml

echo -e "\n3. Latest release:"
ls -lhd /srv/w3ai-updates/v*/

echo -e "\n4. Nginx status:"
systemctl is-active nginx

echo -e "\n5. SSL certificate validity:"
echo | openssl s_client -servername updates.w3ai.dev -connect updates.w3ai.dev:443 2>/dev/null | \
  openssl x509 -noout -dates

echo -e "\n6. Recent access log:"
tail -5 /var/log/nginx/updates.w3ai.dev.access.log

echo -e "\n✅ Health check complete"
BASH

chmod +x /home/deploy/check-updates.sh

# Run it
/home/deploy/check-updates.sh
```

### 3.2 Monitor Update Check Requests

```bash
# Watch for update checks in real-time
ssh deploy@updates.w3ai.dev 'tail -f /var/log/nginx/updates.w3ai.dev.access.log | grep update.xml'

# Parse update statistics
ssh deploy@updates.w3ai.dev << 'SSH'
grep "update.xml" /var/log/nginx/updates.w3ai.dev.access.log | \
  awk '{print $1, $4, $9}' | \
  sort | uniq -c | sort -rn | head -20
SSH

# Count downloads by channel
ssh deploy@updates.w3ai.dev << 'SSH'
for channel in dev rc prod; do
  count=$(grep -c "$channel/macos/update.xml" /var/log/nginx/updates.w3ai.dev.access.log)
  echo "$channel: $count update checks"
done
SSH
```

### 3.3 Maintenance Tasks

```bash
# Monthly: Archive old access logs
ssh deploy@updates.w3ai.dev << 'SSH'
gzip /var/log/nginx/updates.w3ai.dev.access.log.1
mv /var/log/nginx/updates.w3ai.dev.access.log.*.gz /srv/w3ai-updates/logs/
SSH

# Quarterly: Clean old releases
ssh deploy@updates.w3ai.dev << 'SSH'
# Keep only last 3 versions
cd /srv/w3ai-updates
ls -1d v* | sort -rV | tail -n +4 | xargs -I {} rm -rf {}
SSH

# Verify checksums (monthly)
ssh deploy@updates.w3ai.dev << 'SSH'
cd /srv/w3ai-updates/v151.0.0
sha512sum -c checksums.txt
SSH
```

### 5.2 DDoS Protection (Optional)

```bash
# Use CloudFlare to protect against DDoS
# Settings in CloudFlare dashboard:
# - Enable DDoS Protection: Yes
# - Under Attack Mode: Can enable manually if needed
# - Cache Level: Standard
# - Browser Cache TTL: 4 hours
# - Auto Minify: Enable (CSS, JavaScript)
```

### 5.3 Rate Limiting

```bash
# In Nginx config, add rate limiting:
limit_req_zone $binary_remote_addr zone=manifest:10m rate=10r/s;
limit_req_zone $binary_remote_addr zone=download:10m rate=3r/s;

location ~ /(dev|rc|prod)/macos/update\.xml$ {
    limit_req zone=manifest burst=30 nodelay;
    # ... rest of config
}

location ~ /v[0-9]+\.[0-9]+\.[0-9]+/ {
    limit_req zone=download burst=5 nodelay;
    # ... rest of config
}
```

## Troubleshooting

### Problem: 404 Not Found for update.xml

```bash
# Check file exists
ssh deploy@updates.w3ai.dev 'ls -la /srv/w3ai-updates/prod/macos/update.xml'

# Check permissions
ssh deploy@updates.w3ai.dev 'stat /srv/w3ai-updates/prod/macos/update.xml'
# Should be readable (644 or similar)

# Check Nginx can access
ssh deploy@updates.w3ai.dev 'sudo nginx -t'
```

### Problem: SSL Certificate Error

```bash
# Check certificate expiration
echo | openssl s_client -servername updates.w3ai.dev -connect updates.w3ai.dev:443 2>/dev/null | \
  openssl x509 -noout -dates

# Renew certificate manually
ssh root@updates.w3ai.dev 'certbot renew --force-renewal'
```

### Problem: Slow Downloads

```bash
# Check bandwidth usage
ssh deploy@updates.w3ai.dev 'iftop -i eth0'

# Enable compression in Nginx (already configured)
# Monitor Nginx worker processes
ssh deploy@updates.w3ai.dev 'ps aux | grep nginx'
```

## Automation: Auto-Deploy Script

Save this as `deploy-updates.sh` locally:

```bash
#!/bin/bash
set -e

VERSION="$1"  # e.g., v151.0.0
CHANNEL="${2:-prod}"
SERVER="deploy@updates.w3ai.dev"

if [ -z "$VERSION" ]; then
  echo "Usage: ./deploy-updates.sh v151.0.0 prod"
  exit 1
fi

echo "🚀 Deploying W3Ai Browser $VERSION to $CHANNEL channel"

# Get build info
DMG="obj-x86_64-apple-darwin25.3.0/dist/W3AiBrowser-${VERSION}.dmg"
if [ ! -f "$DMG" ]; then
  echo "❌ DMG not found: $DMG"
  exit 1
fi

SIZE=$(du -b "$DMG" | awk '{print $1}')
HASH=$(shasum -a 512 "$DMG" | awk '{print $1}')
BUILD_DATE=$(date '+%Y%m%d%H%M%S')

echo "📦 DMG: $DMG"
echo "📏 Size: $SIZE bytes"
echo "🔐 Hash: ${HASH:0:32}..."

# Create manifest
MANIFEST=$(mktemp)
cat > "$MANIFEST" << EOF
<?xml version="1.0" encoding="UTF-8"?>
<updates>
  <update 
    type="minor" 
    version="${VERSION#v}" 
    extensionVersion="${VERSION#v}" 
    buildID="$BUILD_DATE"
    channel="$CHANNEL"
  >
    <patch 
      type="complete" 
      URL="https://updates.w3ai.dev/${VERSION}/W3AiBrowser-${VERSION}.dmg" 
      hashFunction="sha512" 
      hashValue="$HASH" 
      size="$SIZE"
    />
  </update>
</updates>
EOF

# Upload DMG
echo "📤 Uploading DMG..."
ssh "$SERVER" "mkdir -p /srv/w3ai-updates/${VERSION}"
scp -p "$DMG" "$SERVER:/srv/w3ai-updates/${VERSION}/"

# Upload checksums
echo "📤 Uploading checksums..."
ssh "$SERVER" "cd /srv/w3ai-updates/${VERSION} && shasum -a 512 *.dmg > checksums.txt"

# Update manifest
echo "📝 Updating manifest..."
scp -p "$MANIFEST" "$SERVER:/srv/w3ai-updates/${CHANNEL}/macos/update.xml"

# Verify
echo "✅ Verifying..."
curl -s "https://updates.w3ai.dev/${CHANNEL}/macos/update.xml" | xmllint - > /dev/null

rm "$MANIFEST"
echo "✅ Deployment complete!"
echo "📢 Update available at: https://updates.w3ai.dev/${VERSION}/"
```

Usage:

```bash
chmod +x deploy-updates.sh
./deploy-updates.sh v151.0.0 prod  # Deploy to production
./deploy-updates.sh v151.0.0 rc    # Deploy to RC
./deploy-updates.sh v151.0.0 dev   # Deploy to dev
```
